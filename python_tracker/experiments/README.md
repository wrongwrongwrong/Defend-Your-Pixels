# Experiments

This folder is for reference-only scripts and historical prototypes.

Rules
- Do not treat files here as the current runtime entrypoint.
- Use `runner/` for startup.
- Keep C++-influenced or one-off prototype code here when it is still useful for reference.

Current files
- `reference_camera_preview.py`: old camera preview prototype
- `reference_aruco_preview.py`: old standalone ArUco preview prototype
- `reference_atk_def_board_labels.py`: prototype for labeling ATK / DEF / BOARD markers
- `reference_cpp_overlay.py`: AR overlay experiment derived from the earlier C++ prototype
